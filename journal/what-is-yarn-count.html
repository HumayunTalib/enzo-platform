What Is Yarn Count? A Guide for Fabric Buyers

Cluster: Yarn · Primary keyword: what is yarn count

Yarn count is one of the most commonly misread numbers in textile specifications, because the scale runs opposite to what most people expect: a higher count number means a finer yarn, not a thicker one.

What yarn count actually measures

In the English cotton count system (the most common system referenced in this market), yarn count expresses how many 840-yard lengths of yarn weigh one pound. A higher number means more of those lengths are needed to reach a pound — which means each individual strand is finer. A "40s" count yarn is finer than a "20s" count yarn.

The rule to remember: higher count number = finer yarn = generally lighter, more refined fabric, all else equal. This trips up more buyers than any other textile term — worth committing to memory before you read a specification sheet.

How yarn count relates to warp and weft

Warp and weft counts are specified separately, since a mill can run a different fineness in each direction — see our piece on warp vs weft for why. A construction spec like "40 warp / 30 weft" tells you the warp yarn is finer than the weft.

How yarn count affects the finished fabric

  • Weight. Finer yarn generally produces a lighter fabric at the same construction density — see how yarn count affects fabric weight, hand and cost.
  • Hand. Finer yarn typically produces a smoother, more refined feel.
  • Cost. Finer yarn is generally more expensive to spin.
  • Strength per strand. A single finer strand is weaker than a single coarser one, though this is compensated for by construction density and twist.

Other counting systems

The English cotton count (Ne) system is the most commonly referenced in Pakistani textile trade, but denier (used for filament yarns like polyester and silk) and metric count (Nm) are also used depending on fibre type — denier runs in the opposite direction to cotton count, with a HIGHER denier number meaning a THICKER yarn. Always confirm which system a specification is using before comparing numbers across suppliers.

Frequently asked questions

Does a higher yarn count number mean better quality?

It means finer, not automatically better — a finer yarn suits a lighter, more refined fabric; a coarser yarn suits a heavier, more durable one. Match the count to the intended fabric, not to "higher is better."

Is denier the same scale as cotton count?

No — they run in opposite directions. Higher denier means thicker yarn; higher cotton count means finer yarn. Always check which system a spec sheet is using.
